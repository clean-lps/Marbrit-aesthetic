## Design Context

### Users
Women interested in facial and body aesthetic treatments around Coral Gables and nearby Miami neighborhoods. They are likely comparing trust, visible results, comfort, and ease of contact before booking. The job to be done is simple: understand what treatments are offered, feel safe with the practitioner, and take the fastest next step through WhatsApp or booking.

### Brand Personality
Warm, feminine, reassuring, and visibly beauty-led. The current materials suggest an accessible premium tone rather than cold clinical luxury. The interface should evoke confidence, care, and visible transformation without feeling generic or overly medical.

### Aesthetic Direction
The existing brand assets point to coral blush, soft rose, navy, white, and treatment photography. The next version should keep the feminine warmth but increase clarity, hierarchy, and trust. Avoid template-like medspa clichés, default purple gradients, or abstract beauty visuals that disconnect from real treatments.

### Implementation Defaults
- Framework/runtime detected in repo: React 19 + TypeScript + Vite
- Styling system detected in repo: Tailwind v4 + global CSS variables in `src/index.css`
- Component ecosystem detected in repo: mixed `@base-ui/react`, Radix primitives, and shadcn-generated components
- Motion already available: `motion`, `framer-motion`, `gsap`, `lenis`
- Forms available: `react-hook-form` + `zod`
- SEO available: `react-helmet-async`
- Current baseline app state: starter shell only, no real landing implemented yet
- Precedence: existing repo stack should be preserved; no new dependency is needed for the first landing pass

### Design Principles
- Show real treatments fast: the first viewport should prove this is an aesthetics business, not a generic service template.
- Put trust before decoration: clear service language, real imagery, proof, and contact paths matter more than visual effects.
- Make WhatsApp the obvious action: every major section should support a fast message-first conversion path.
- Keep the palette warm but grounded: coral and blush can lead, but navy or deep neutrals should carry credibility and contrast.
- Use sections with specific jobs: each block should either explain treatments, reduce doubt, prove expertise, or move the visitor toward contact.
